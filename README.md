Projects implemented in MIPS Assembly Language using PC-SPIM:

Project 1: Introduction to the PC-SPIM environment and basic MIPS Assembly I/O operations, including handling strings, integers, and characters.

Project 2: Implementation of an arithmetic operations program in MIPS Assembly that processes two numbers and an operator using ASCII values and proper register conventions, with a bonus for hexadecimal operations.

Project 3: Development of a text-processing string manipulator in MIPS Assembly utilizing loops, memory addressing, byte-level processing, logical operations, and basic procedures without a stack.

Project 4: Implementation of a simple phone book directory in MIPS Assembly supporting entry creation and record inquiries using data structures, field addressing, and nested procedures with stack-managed return addresses.

Project 5: Development of a recursive algorithm in MIPS Assembly to compute Fibonacci numbers, utilizing stack-based argument passing, return values, and ASCII conversion for formatted console output.
